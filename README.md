# RF-Hunter
<img width="1366" height="768" alt="image" src="https://github.com/user-attachments/assets/eaba84d1-ef0e-48bb-af78-945a19a7e448" />

Tool that measures the Radio Frequency in a specific location.

My version of the RF-Hunter is a simple, small gadget made from a HMC849A chip and a GRF1201 chip. It also has two antennas, one 2.4GHz and one 5GHz. They switch periodically to measure the amount of radio frequency coming from a specific location.
This way, you can have fun while searching for what device could be emmitting those particular radio waves.

The PCB works on a common ESP32-WROOM-32 DevkitC. You can choose your own screen to use, the 3d printing models and code will need to be adapted! I decided to use a DFR0664 for myself.
